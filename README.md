# Sky Forge Solutions — Static Website

A responsive static website for Sky Forge Solutions, based on the supplied brochure content and branding.

## Files
- `index.html` — website structure and content
- `styles.css` — responsive styling and branding
- `script.js` — mobile navigation and current year
- `assets/sky-forge-logo.png` — Sky Forge Solutions logo

## Run locally
Open `index.html` directly in a browser, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy
Upload the contents of this folder to any static hosting service. No backend or database is required.
